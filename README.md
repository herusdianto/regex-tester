# Regex Tester

A simple, client-side regex testing tool - test your regular expressions directly from your browser.

## Features

- **Regex Pattern Input**: Enter your regular expression pattern
- **Test String**: Input text to test against your regex
- **Match Results**: View all matches with their positions
- **Flags Support**: Toggle common regex flags (g, i, m, s)
- **Match Groups**: Display captured groups separately
- **Real-time Testing**: Results update as you type
- **Dark/Light Mode**: Toggle between themes
- **100% Client-side**: All processing happens in your browser, no data sent to any server

## Usage

1. Enter your regex pattern in the pattern input field
2. Add any flags you need (g, i, m, s)
3. Enter or paste your test string
4. View matches, groups, and match positions in real-time

## Features in Detail

### Pattern Input
- Supports full JavaScript regex syntax
- Real-time validation with error messages
- Flag toggles for global, case-insensitive, multiline, and dotall modes

### Test String
- Multi-line text input
- Real-time matching as you type
- Clear visual feedback for matches

### Results Display
- **Matches Tab**: Shows all matched text with positions
- **Groups Tab**: Displays captured groups separately
- **Details Tab**: Shows match count and pattern information

### History
- Automatically saves last 50 regex patterns
- Load previous patterns with one click
- Clear all history option

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- Vanilla JavaScript (ES6+)
- Local Storage for history persistence

## Browser Support

Works in all modern browsers that support:
- CSS Grid
- CSS Variables
- ES6 Classes
- Regular Expressions
